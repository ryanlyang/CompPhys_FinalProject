\subsection{AspenOpenJets Shift}

Each of the five baseline seed models was evaluated on $10^6$ AspenOpenJets jets. Table~\ref{tab:aspen-shift} shows large distributional shifts across all seeds. I initially attempted to convert these unlabeled shift metrics into a pseudo-accuracy drop using the controlled JetClass corruption calibration, but that conversion did not hold up well enough to report as a result. The AspenOpenJets points were often outside the controlled corruption range, making the inferred accuracy shifts highly extrapolation-sensitive. Therefore, the reported Aspen result is the direct unlabeled shift itself, not a pseudo-accuracy estimate.

This is an important distinction. The shift metrics are still useful because they quantify how much the model's prediction distribution changes on real CMS-derived jets, and the strongest metrics were validated against labeled JetClass corruptions. However, the separate ``unlabeled shift metric $\rightarrow$ accuracy shift'' mapping was not stable enough to include quantitatively. That failure is itself informative: it shows that the project can identify distribution shift, but measuring real-data accuracy without labels requires stronger validation tools than this project had available.

\subsection{Interpretability-Guided Training}

The RRR-style training study used a focused 24-configuration sweep: three attribution-mask sources, two regularization strengths $\lambda_{\mathrm{RRR}}\in\{1,10\}$, and four mask fractions $\{0.05,0.10,0.20,0.30\}$. I initially intended to run a wider hyperparameter scan, but the larger grid was not practical on the project timescale. The main reason is that a single hyperparameter configuration required five full from-scratch trainings for the find-another loop. Each iteration also required JetClass evaluation and AspenOpenJets inference, and iterations 2--5 required full-training-set attribution passes to construct the next cumulative mask. I also did not use Integrated Gradients or SmoothGrad directly as the differentiable in-training regularizer. Doing so would require many additional gradient evaluations inside every training step, which was too expensive for the project timescale. Instead, the actual RRR penalty used input gradients, while Integrated Gradients and SmoothGrad were still implemented as attribution methods for constructing the masks used between find-another iterations.

For comparison, the seed-52 baseline has JetClass accuracy $0.7425$, macro AUC $0.9638$, and strong3 Aspen shift $0.6199$. All 24 configurations in the focused sweep reduced strong3 relative to this baseline. Figure~\ref{fig:rrr-tradeoff} shows the accuracy-shift tradeoff: the RRR runs move downward in Aspen strong3, but also move left in JetClass accuracy. Table~\ref{tab:rrr-top6} reports the six focused-sweep configurations with the lowest AspenOpenJets strong3 values, while Table~\ref{tab:rrr-best-source} reports the best configuration for each attribution-mask source. Within each run, the reported iteration is selected by minimum AspenOpenJets strong3 shift, not by JetClass accuracy. The tables then report the corresponding JetClass test accuracy for that selected iteration.

The best focused-sweep configuration reduced strong3 by about $24\%$ relative to the baseline, but reduced JetClass accuracy by about $4.9$ percentage points. A more balanced input-gradient configuration, $\lambda=1$ and mask fraction $0.30$, reduced strong3 by about $17.5\%$ while reducing JetClass accuracy by about $3.1$ percentage points. These results show that the intervention is not merely random regularization: it consistently changes the model in the direction of lower AspenOpenJets shift, while exposing a clear performance tradeoff.

This improvement should be interpreted as a reduction in unlabeled prediction-distribution shift, not as a direct measurement of AspenOpenJets accuracy. The metric is useful because it was calibrated against controlled JetClass corruptions and passed the pipeline sanity checks, but it remains an imperfect proxy for real-data performance. Confirming that the same intervention significantly improves real collision-data classification would require a larger study with more AspenOpenJets data, stronger target-domain validation metrics, and substantially more research compute than was available for this project.

Figure~\ref{fig:rrr-heatmaps} shows the same focused sweep organized by hyperparameter cell. The best cell uses SmoothGrad masks with $\lambda_{\mathrm{RRR}}=10$ and mask fraction $0.05$. The pattern should not be overinterpreted as a global optimum, since larger $\lambda_{\mathrm{RRR}}$ values were left for future work, but it does show that the improvement is not isolated to a single accidental run.
