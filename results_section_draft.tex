\subsection{Interpretability-Guided Training}

The RRR style of training study used a focused 24 configuration sweep, three attribution-mask sources, two regularization strengths  $\lambda_{\mathrm{RRR}}\in\{1,10\}$, and four mask fractions $\{0.05,0.10,0.20,0.30\}$. I initially intended to run a wider hyperparameter sweep, but the larger grid did not prove doable on the project timescale and resources. I also did not rerun the setups for more than one seed as I did for the baseline, as that was also a very expensive cost. I also did not use Integrated Gradients or SmoothGrad directly as the differentiable in-training regularizer. Doing so would require many more gradient evaluations inside each training step, which was just too expensive for my compute resources. Instead, the actual RRR penalty used input gradients, while Integrated Gradients and Smooth Grad were still implemented as attribution methods for constructing the masks used between find-another iterations.

For comparison, the 5-seed baseline has JetClass accuracy as  $0.7459$, macro AUC $0.9638$, and strong3 Aspen shift $0.6199$. All 24 configurations in the focused sweep reduced strong3 relative to this baseline. Figure~\ref{fig:rrr-tradeoff} shows the accuracy-shift tradeoff: the RRR runs move downward in Aspen strong3, but also move leftward in JetClass accuracy. Table~\ref{tab:rrr-top6} reports the six focused-sweep configurations that have the lowest AspenOpenJets strong3 values, while Table~\ref{tab:rrr-best-source} reports the best configuration for each of the attribution-mask source methods. Within each of the runs, the reported interaction is selected by minimum	AspenOpenJets strong3 shift, not by JetClas accuracy. The tables then report the corresponding JetClass test accuracy for that selected iteration.

The best focused-sweep configuration reduced the strong3 metric by about $24\%$ relative to the baseline, but it reduced JetClass accuracy by about $4.9$ percentage points. A more balanced input gradient configuration such as $\lambda=1$ and mask fraction $0.30$, reduced strong3 by about $17.5\%$ while reducing JetClass accuracy by about $3.1$ percentage points. These results show that the intervention is not just random regularization, it consistently changes the model in the direction of lower AspenOPenJets shift, while showing a non-negligible performance trade.

This improvement should be interpreted as a reduction in the unlabeled prediction-distribution shift, not as a direct measurement of AspenOpenJets accuracy. The metric is useful because it was calibrated against controlled JetClass corruptions and passed the pipeline sanity checks, but it is still an imperfect proxy for real-data performance. Confirming that the same intervention significantly improves the real collision-data classification would require a larger study with different kinds of data, stronger target-domain metrics, and more research compute then was available for the scope of this project.

Figure~\ref{fig:rrr-heatmaps} shows the same focused sweep organized by hyperparameter cell. The best cell uses SmoothGrad masks with $\lambda_{\mathrm{RRR}}=10$ and mask fraction $0.05$.. The pattern should not be interpreted as a global best, since larger and more diverse $\lambda_{\mathrm{RRR}}$ values were left for future work, but it does show that the improvement is not isolated to a single random run.
